# Google Sheets и Apps Script

Основная база — D1. Таблица — зеркало для учёта, изменения в ней не передаются обратно в магазин. Управляйте товарами и статусами в админ-панели.

Рабочая таблица: https://docs.google.com/spreadsheets/d/1wCPcFAoy2yHhqpPPall35FYa9pdTeCRJAPzAsCLSgBg/edit

Apps Script: https://script.google.com/home/projects/12SgieGXdXD98XuWrfn3ZLOJQEO2KeJsNsyZxM0WsBajSTZ-EVZ41FyJ_/edit

Владелец: kvitbloom@gmail.com. Листы: Заказы, Состав заказов, Товары, Движение остатков. Чеки остаются приватными в магазине; в таблице хранится ID чека, сам чек открывается в админ-панели.

## Подключение

1. Применить миграции `0000` и `0001`. На Sites это происходит при публикации.
2. На сервере задать секрет `SHEETS_SYNC_KEY` (случайное значение не короче 32 символов).
3. В свойствах привязанного Apps Script задать `SYNC_KEY` с тем же значением, `SHOP_URL` — HTTPS origin магазина. Для приватного Sites также нужен `SITES_TOKEN`, который разрешает серверный доступ через внешнюю страницу входа. Не помещать ключи в Git или ячейки.
4. Скопировать `Code.gs` в редактор Apps Script. Выполнить `installSync`, выдать необходимые разрешения Google. Эта функция проверяет соединение, затем создаёт триггер `syncShop` раз в минуту. Повторный запуск не создаёт второй триггер.

## Надёжность и обслуживание

Триггеры D1 записывают события в той же транзакции, что и изменения. `CURSOR` в свойствах скрипта сдвигается только после успешной записи всех четырёх листов. Повтор записывает строку с тем же ID, не создавая дубликатов. Параллельные запуски блокируются через LockService. За один запуск обрабатывается до пяти страниц по 100 событий. Интервал Google не гарантирует доставку ровно через 60 секунд.

`LAST_SUCCESS` и `LAST_ERROR` в свойствах скрипта показывают состояние. Ошибки видны в разделе «Количество выполнений». После восстановления доступа следующий запуск повторяет необработанную страницу. Для восстановления удалённых строк можно установить `CURSOR=0` и выполнить `syncShop`; журнал пока не очищается.

Движение остатков начинается с момента подключения. Исторические движения до подключения не выдумываются: фиксируется текущий остаток. Деньги в базе — целые копейки, в таблице — гривны. Идентификаторы и телефоны сохраняются текстом; пользовательский ввод не исполняется как формула.

При переносе на другой хост обновить `SHOP_URL` в свойствах скрипта и настроить серверный секрет и хранилища на новом хосте. При публичном размещении вне Sites удалить ненужный `SITES_TOKEN`.
